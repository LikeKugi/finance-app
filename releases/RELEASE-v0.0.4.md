# FinanceApp v0.0.4 — Обновление

> 21 ноября 2026

## Обзор

Версия 0.0.4 приносит значительные улучшения во все модули приложения: новые справочники мест трат, произвольные названия платёжных карт, настраиваемые таблицы с сохранением ширины столбцов, расширенные фильтры транзакций, раздельный анализ по валютам RUB и USD, улучшенные круговые диаграммы, а также поддержку сборки и релизов для macOS.

---

## Новые возможности

### Места трат

- **Новый справочник «Места трат»** — создавайте, редактируйте и удаляйте места, где вы совершаете покупки (магазины, кафе, сервисы).
- **Связь расходов с местами трат** — при создании или редактировании расхода можно указать место через выпадающий список.
- **Фильтр по месту трат** — на страницах «Доходы» и «Расходы» появился дополнительный фильтр для быстрого отбора операций по конкретному месту.
- **Миграция V11** — добавлена таблица `expense_places` и поле `expense_place_id` в таблицу `expenses`.

### Платёжные документы

- **Произвольное название карты** — теперь каждой карте можно задать собственное имя (например, «Основная», «Путешествия»). Название отображается в таблице и в фильтрах.
- **Валидация названия** — пустое или состоящее только из пробелов название отклоняется с понятным сообщением об ошибке.
- **Настраиваемая таблица** — ширина столбцов настраивается и сохраняется между запусками; столбец «Действия» имеет фиксированную ширину.
- **12 столбцов** — название, банк, платёжная система, тип, сумма, валюта, дата платежа, льготный период, ставка, порог, связанные вклады, действия.

### Фильтры транзакций

- **Фильтр по банку** — отбирайте операции, связанные с конкретным банком.
- **Фильтр по карте** — отбирайте операции по конкретной платёжной карте; при смене банка фильтр карты сбрасывается.
- **Фильтр по месту трат** — отбирайте расходы по месту совершения.
- **Умная фильтрация** — фильтры по банку и карте координируются: выбор банка обновляет доступный список карт.

### Аналитика

- **Раздельные итоги RUB и USD** — отчёт анализа теперь показывает суммы, доли и круговые диаграммы отдельно для каждой валюты. RUB и USD больше не смешиваются в одном итоге.
- **Настраиваемая таблица** — ширина столбцов настраивается и сохраняется; поддерживается сортировка по любому столбцу.
- **Улучшенные круговые диаграммы** — переработано отображение секторов с улучшенной читаемостью и цветовой палитрой.
- **Индикатор загрузки** — при вычислении отчёта таблица показывает состояние загрузки.
- **Функция `summarize_transaction_balance`** — добавлена в `finance-core` для расчёта баланса транзакций.

### Накопления

- **Настраиваемая таблица** — перешла на делегат таблицы с сохранением ширины столбцов между запусками.
- **Улучшенное отображение** — переработаны столбцы и форматирование значений.

### Справочники

- **Места трат** — новый раздел справочников с полным CRUD: создание, редактирование, удаление с подтверждением.
- **Форма с комментариями** — при создании или редактировании места трат можно добавить комментарий.

### Настройки

- **Версия приложения** — на странице настроек отображается текущая версия приложения.
- **Функция экспорта** — добавлена возможность экспорта данных со страницы настроек.

## Технические детали

### Миграция базы данных

Добавлена миграция **V11** (`V11__expense_places_and_card_names.sql`):

- `ALTER TABLE payment_documents ADD COLUMN name` — произвольное название карты.
- `CREATE TABLE expense_places` — справочник мест трат с полями `id`, `name`, `comment`.
- `ALTER TABLE expenses ADD COLUMN expense_place_id` — связь расхода с местом трат.
- `CREATE INDEX expenses_expense_place_id_idx` — индекс для ускорения запросов.

### Изменения в `finance-core`

- Добавлена модель `ExpensePlace`.
- Добавлено поле `expense_place_id` и `expense_place_name` в `FinancialTransaction`.
- Добавлено поле `name` в `PaymentDocument` и `PaymentDocumentDetails`.
- Добавлена валидация `name` для платёжных документов.
- Добавлена функция `summarize_transaction_balance`.
- Добавлен тип ошибки `InvalidPaymentDocumentName`.

### Изменения в `finance-db`

- Репозиторий расширен поддержкой CRUD операций для `expense_places`.
- Добавлены методы `list_expense_places`, `insert_expense_place`, `update_expense_place`, `delete_expense_place`.
- Обновлены запросы для загрузки транзакций с учётом `expense_place_id`.
- Обновлены запросы для загрузки платёжных документов с учётом поля `name`.
