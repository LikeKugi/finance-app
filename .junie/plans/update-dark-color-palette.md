# Требования

### Цель
Заменить цвета тёмной темы на значения из предоставленной таблицы для всех ролей интерфейса и подсветки редактора, а также обновить отдельную палитру восьми секторов диаграммы FinanceApp.

### Объём и ограничения
- Применять новую палитру только при активной тёмной теме — в том числе когда режим `Системная` разрешился в тёмный.
- Не менять светлую тему, доступные настройки режима, их сохранение или финансовую логику.
- Сохранить значения прозрачности в цветах с alpha-каналом.
- Хранить конфигурацию в проекте; не редактировать файлы установленной зависимости в кэше Cargo.

# Технический дизайн

### Текущее устройство
- `crates/ui/src/gpui/settings.rs`: `ThemePreference::apply` переключает режим через `Theme::change` или синхронизирует системный вид; выбор темы загружается при открытии настроек и применяется при выборе пользователем.
- `gpui-kit` версии `0.10.0` предоставляет `ThemeConfig` для ролей компонентов и подсветки, а `ThemeRegistry::load_themes_from_str` — для регистрации проектной конфигурации. Изменение нужно применять после определения эффективного режима, чтобы переключение не перезаписывало кастомные значения.
- `crates/ui/src/gpui/analysis.rs`: восемь цветов секторов диаграммы заданы отдельно в `PIE_CHART_COLORS` и не берутся из темы.

### Решение
Добавить принадлежащую проекту конфигурацию тёмной темы на базе `ThemeConfig` и применять её через существующий жизненный цикл темы в `ThemePreference::apply`. В конфигурацию перенести все предоставленные новые значения: роли интерфейса, графики, базовые цвета, фон и текст редактора, состояния подсветки и цвета синтаксиса. Цвета диаграммы обновить в `PIE_CHART_COLORS` согласно таблице; оставить их независимыми от режима темы.

### Файлы
- Добавить конфигурацию тёмной темы в проектные ресурсы, например `assets/themes/financeapp-dark.json`.
- Изменить `crates/ui/src/gpui/settings.rs`, чтобы проектная тёмная конфигурация использовалась и для режима `Тёмная`, и для `Системная` при тёмном оформлении; для `Светлая` оставить штатную конфигурацию.
- Изменить `crates/ui/src/gpui/analysis.rs`, заменив значения `PIE_CHART_COLORS`.

# Delivery Steps

### ✓ Step 1: Добавить и подключить проектную тёмную тему
Проект использует заданную тёмную палитру, включая цвета редактора, независимо от файлов кэша Cargo.
- Добавить принадлежащую проекту конфигурацию `ThemeConfig` со всеми значениями из таблицы, сохранив прозрачность цветов.
- Зарегистрировать конфигурацию через API `ThemeRegistry` и подключить её в `ThemePreference::apply` после разрешения режима.
- Применять её в режимах `Тёмная` и `Системная` при активном тёмном оформлении; не менять штатную светлую тему и сохранение настройки.
- Добавить проверку загрузки конфигурации и ключевых значений палитры, включая цвета редактора и alpha-каналы.

### ✓ Step 2: Обновить цвета диаграммы и проверить результат
Диаграмма анализа использует новые восемь цветов из таблицы, а изменения палитры проходят проверки.
- Заменить значения `PIE_CHART_COLORS` в `crates/ui/src/gpui/analysis.rs` на новые цвета секторов.
- Проверить соответствие всех восьми значений и циклическое назначение цветов категориям.
- Запустить `cargo fmt --all -- --check`, `cargo check --workspace --all-targets --locked` и `cargo test --workspace --locked`; сообщить о результатах.
