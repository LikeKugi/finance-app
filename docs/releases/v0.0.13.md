# FinanceApp v0.0.13 — аналитика, категории и интерфейс

**Дата:** 28 ноября 2026 года  
**Тег для публикации:** `v0.0.13` (совпадает с версией в `crates/app/Cargo.toml`)  
**Диапазон изменений:** `f410b7a..HEAD`

## Что нового

### Аналитика

- Добавлены подробные отчёты по категориям, платёжным документам, банкам, накоплениям, местам расходов и валютам.
- В подробном анализе расходов показаны отдельные итоги регулярных расходов; также исправлено отображение нижней части таблицы.
- В таблицу анализа добавлена графическая колонка для визуального сравнения расходов.

### Справочники

- При первоначальном создании базы данных инициализируются иерархии категорий доходов и расходов. Уже существующие базы при обновлении повторно не заполняются.

### Интерфейс и CI

- В полноэкранном режиме Windows для системных кнопок окна резервируется место в панели вкладок; кнопка закрытия окна выделена цветом опасного действия.
- Добавлен запуск тестов workspace при `push` и `pull_request`; workflow сборки артефактов теперь запускается для pull request.

## Проверки

- `cargo +stable build -p finance-app --release --locked` — OK.

Полная история изменений: `f410b7a..HEAD` (12 коммитов).
